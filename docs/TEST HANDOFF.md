# 영상 레퍼런스 워크플로 핸드오프

작성: 2026-09-27. 이 문서는 구현 요청이 아닌, 다른 개발자/에이전트에게 현재 합의와 관찰 결과를 전달하기 위한 것이다.

## 목적과 범위
사용자가 Instagram Reel 또는 YouTube Short 링크를 보내면, 실제 영상을 보고/듣고 대표 장면 3~4장과 말 받아쓰기, 요약, 영상 레퍼런스용 분류를 파악해 정적 웹페이지 콘텐츠로 넣고 발행한다. 장차 링크를 축적해 썸네일 기반 목록에서 한눈에 살펴보고 검색할 수 있는 시스템을 구상 중이다.

## 확인된 사용자 요구
- 링크 메타데이터뿐 아니라 실제 영상·음성을 확인할 것.
- 캡처 이미지는 말로만 설명하지 말고 파일로 보내기 (`MEDIA:/absolute/path`). 대표 장면 **최소 3~4개(길면 더)**.
- 말 받아쓰기/대본을 함께 제공. STT 오류나 불명확한 구간을 분리할 것.
- 분류는 PARA 프로젝트/영역/자료가 아니라 **영상 레퍼런스의 검색·재활용 목적**으로 제안할 것.
- 아직 자동 저장·시스템 등록은 하지 않음.

1. Instagram `Dbi2JNzRFE5`: 약 8초짜리 고양이 두 마리·파도 영상. `yt-dlp` 메타데이터 설명은 `@thv`의 할리우드 공연 관람에 관한 일본어 문구였으며 **영상과 불일치**. 메타데이터를 줄거리로 쓰면 안 되는 사례.
2. Instagram `DdczWD4zgcl`: 약 26초. 힉스필드 API로 구독 대신 사용량에 따라 결제하라고 홍보하며 `API keys → 키 생성 → 키 복사 → GPT 연결`을 소개. ‘할인된 가격’은 영상 속 **주장**이지 독립 검증된 요금 비교가 아님. 게시물 설명과 영상의 취지는 대체로 일치.
3. YouTube Short `tRJIF5UHUm0`: 약 60초, Studio STEELCUT의 〈AI 로판 [빙의는 했는데 얼굴이 따라왔습니다] 1화〉. AI 제작 로맨스 판타지 패러디 드라마. 추천 **주 분류: AI 제작 숏폼 드라마**, 장르: 로맨스 판타지 패러디·코미디, 참고 요소: 빠른 설정 소개·기대 뒤집기·다음 화 예고. 음성 인식은 긴 귀족식 이름 등에서 오인식이 있었고, 정확한 전문 녹취로 주장하면 안 됨.

## 제안하는 카드 데이터 구조 (미구현. AI의 의견이므로 참고만 할 것)
- `url`, `platform`, `platform_id`, `creator`, `title`, `posted_at`(확인 가능할 때), `duration_s`
- `primary_category`(하나), `genre_tags`(복수), `format_tags`(복수), `reference_points`(재활용할 연출 포인트)
- `one_line_summary`, `scene_summary`, `transcript`(출처/신뢰도 표시), `metadata_mismatch`(있을 때)
- `stills`(3~4개; 각 타임코드·설명), `reviewed_at`, `source_status`(영상 확인/메타데이터만 확인/접근 불가)
- 원본 링크와 내부 식별자로 중복 체크. 제목만으로 중복 판정하지 않음.
- 정적 썸네일 목록 + 주 분류/장르/형식 검색이 첫 구현 후보. 실제 저장소, UI, 파일 형식은 사용자와 결정 전까지 미확정.

## 구현·검수 주의
- `yt-dlp --write-info-json` + `ffprobe` + `ffmpeg`로 추출. YouTube HLS 파일에서는 앞쪽 `-ss`로 캡처하면 요청 시각과 화면이 어긋날 수 있어 `ffmpeg -i INPUT -ss N -frames:v 1 OUT.jpg`로 재추출하고 실제 프레임 검수.
- 공식 자막이 있으면 먼저 확인; 없으면 STT 초안을 화면 자막·음성과 대조. 긴 작품명/인명, 욕설, 빠른 대사에서 모델이 만들어낸 말을 확정하지 않음.
- 실제 영상의 정지 화면만으로 동작·음성·제작 방식을 단정하지 않음. 원본 주장과 독립적으로 확인된 사실을 구분.
- 민감한 콘텐츠나 제3자의 영상은 원본 링크 중심으로 관리하고, 내려받은 원본의 재배포/공개는 별도 결정.
- 예시 스킬 초안: 같은 디렉터리의 `SKILL.md`. **Hermes 스킬 디렉터리 밖에만 존재하며 등록하지 않음.**
